# eventi-estremi-lombardia
Questa repository contiene il materiale della mia tesi di master sull'analisi degli eventi estremi di temperatura massima giornaliera in Lombardia, con un confronto tra aree urbane e rurali.

# Contenuto
- 'tesina.pdf' - il PDF completo della tesina
- 'codice.ipynb' - lo script contenente l'analisi.
- 'dati/' - cartella contenente le cartelle: 'CITTA/', raccolta dei dati provenienti dalle stazioni urbane, 'CAMPAGNA/', raccolta dei dati provenienti dalle stazioni rurali.
